# ShogaiRun
ShogaiRun is a 3D runner game built using **Godot Engine**.  
It features dynamic level design, collectible items, obstacles, and interactive gameplay elements.
This repository contains all assets, scenes, scripts, and resources used in the game.

---

## Built With
- **Godot Engine**
- **GDScript**

---

## Features
- Player controller with movement and custom Rigid Body Physics  
- Collectible items (stars/coins)  
- Obstacles and projectiles
- Particle effects and visual enhancements  
- Sound effects for gameplay feedback
